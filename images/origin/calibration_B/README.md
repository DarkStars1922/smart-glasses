# 智能眼镜退化模型标定图

本目录包含 32 张 `2515 x 1491`、8-bit RGB、无损 PNG 标定图。

## 图像用途

- `00-08`：黑、白和灰阶，用于估计环境反射、黑电平、空间亮度衰减、相机响应曲线和过曝阈值。
- `09-18`：RGB/CMY 纯色与色条，用于估计通道增益、颜色串扰和颜色矩阵。
- `19-21`：棋盘格与非对称网格，用于估计透视、上下/左右翻转和镜头畸变。
- `22-28`：点阵、斜边、分辨率线和 Siemens star，用于估计 PSF、方向性模糊和有效分辨率。
- `29`：空间色块，用于检查颜色和衰减是否随屏幕位置变化。
- `30-31`：黑底白字、白底黑字，用于验证最终退化模型，不建议用它们单独拟合模糊核。

## 拍摄方法

1. 按文件名顺序全屏显示，使用 100% 缩放，禁止图片查看器插值缩放。
2. 固定眼镜和相机位置，每张图连续拍摄至少 10 帧。
3. 锁定曝光、ISO、焦点、焦距和白平衡；关闭 HDR、美颜、夜景增强和场景优化。
4. 先显示 `01_white.png` 调整曝光，确保 RGB 三个通道均不过曝，然后整组保持曝光不变。
5. 每改变一个拍摄角度或距离，都重新完整拍摄一遍 32 张图。
6. 保留拍摄顺序，并让拍摄文件与标定图文件名一一对应。

## 重新生成

依赖 Python、Pillow 和 NumPy。在仓库根目录运行：

```bash
python images/generate_calibration_b.py
```

Codex 工作区自带 Python 时可运行：

```bash
"/c/Users/Darkstars/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe" images/generate_calibration_b.py
```

生成器只会替换本目录下的 `.png` 文件，不会删除本说明文件。
